# Argument

Ein Argument ist ein konkreter Wert, der einer Funktion bei einem Funktionsaufruf 
übergeben wird.

## Beispiele
`print(12)`
: Das Argument des `print`-Funktionsaufrufs ist 12

`print(12+13)`
: Das Argument des `print`-Funktionsaufrufs ist 25 (das Resultat des ausgewerteten Ausdrucks `12+13`)

`print("Hallo")`
: Das Argument ist der [String](/Glossar/String) `Hallo`.

## Mehrere Argumente

Einem Funktionsaufruf müssen genau soviele Parameter mitgegeben werden, wie die Funktion über
Parameter verfügt. Benötigt eine Funktion mehrere Parameter, werden Kommas zur Trennung verwendet.

Beispielsweise benötigt die Funktion `max` mehrere Argumente, z.B. `max(13, 15)`.
