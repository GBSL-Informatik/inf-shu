# String

Ein String ist eine Zeichenkette, d.h. eine Folge von Zeichen. Strings werden in praktisch
allen Programmiersprachen in Anführungszeichen geschrieben. Beispiele:

```"Hallo Welt"```

```"x"```

```"123"```

Beachte, dass auch das letzte Beispiel, ```"123"```, ein String ist, weil die Ziffern 1, 2 und
3 in Anführungszeichen stehen. Wir haben es also mit den drei Zeichen ```"1"```, ```"2"```
und ```"3"``` zu tun, nicht mit der Zahl 123.

## Beachte

   1. Schreibe Zahlen, mit denen du rechnen willst, nie als Strings. "123" und 123 sind nicht 
   dasselbe! Der eine Wert ist vom Type _String_, der andere vom Typ Integer (Ganzzahl). 

   2. Vergiss bei Text die Anführungszeichen nicht! Wenn du ```print(Hallo)``` schreibst statt
   ```print("Hallo")```, kriegst du eine Fehlermeldung, dass der Name `Hallo` nicht definiert
   ist.
