# Huffman-Codierung

Der Huffman-Algorithmus (nach [David A. Huffman](https://de.wikipedia.org/wiki/David_A._Huffman), 
der ihn 1952 publiziert hat) dient zur Kompression beliebiger Daten, welche aus einem Alphabet von
Symbolen bestehen, die unterschiedlich oft auftreten können. 

Ein gutes Beispiel für solche Daten ist ein gewöhnlicher Text in einer beliebigen Sprache. 

Der Huffman-Algorithmus findet den optimalen binären Code für jedes Symbol, wobei «optimal» bedeutet,
dass der resultierende Datenstrom möglichst wenig Redundanz enthält (und damit möglichst wenige Bits).
