# Variablen

Schaue dir noch einmal das Turtle-Programm an, welches ein Pentagon zeichnet:

```py live_py slim
from turtle import *

forward(100)
left(72)
forward(100)
left(72)
forward(100)
left(72)
forward(100)
left(72)
forward(100)
left(72)
```

Wenn wir dieses Pentagon grösser oder kleiner zeichnen wollen, müssen wir die Argumente der 5 `forward`-Befehle
anpassen. Das ist umständlich. Schöner wäre es, wir müssten das Programm nur an einem einzigen Ort ändern.

Das geht tatsächlich, und zwar, indem wir statt die tatsächliche Schrittanzahl (100 Schritte vorwärts) einen
Platzhalter für diese Schritte verwenden:

```py live_py slim
from turtle import *

seitenlänge = 100

forward(seitenlänge)
left(72)
forward(seitenlänge)
left(72)
forward(seitenlänge)
left(72)
forward(seitenlänge)
left(72)
forward(seitenlänge)
left(72)
```

Den Namen `seitenlänge` können wir frei wählen, wir hätten auch `s` oder `x` oder `maxli` verwenden
können. Der Name fungiert als Platzhalter für den Wert 100. Dafür sorgt die Zeile

    seitenlänge = 100

Das ist *nicht* eine mathematische Gleichung, sondern eine **Zuweisung**: Sie **bindet** den Namen 
`seitenlänge` an den Wert 100.

Solche Platzhalter nenen wir **Variablen**.

Wenn du die Grösse des Pentagons ändern willst, musst du dies nun nur noch an einer einzigen Stelle tun.

## Variablen behalten ihre Werte nicht für immer

Eine Zuweisung gilt nicht für immer. Variablen sind keine Konstanten, d.h. sie müssen
nicht über das ganze Programm hinweg an die gleichen Werte gebunden sein. Hier ist ein
Beispiel, welches dir zeigt, wie der Wert einer Variablen ändern kann:

```py live_py slim
lustiger_komiker = 'Mr Bean'
print(lustiger_komiker)
lustiger_komiker = 'John Cleese'
print(lustiger_komiker)
```

Variablen können also an einen neuen Wert gebunden werden, wenn eine neue Zuweisung 
für den gleichen Namen ausgeführt wird.

Das bedeutet auch, dass du eine Variable erst verwenden kannst, wenn du ihr einen Wert
zugewiesen hast. Es hilft nicht, dass im Programm später irgendwann ein Wert zugewiesen
wird, wenn er **jetzt** gebraucht wird:

```py live_py slim
print(lustiger_komiker)
lustiger_komiker = 'Mr Bean'
```

Der kryptische rote Text ist eine Fehlermeldung. Python beklagt sich, dass der Name
`lustiger_komiker` in Zeile 1 undefiniert ist, d.h. dass der Name nicht an einen Wert
gebunden ist. Python kann den Wert nicht anzeigen, weil der Wert erst in der nächsten
Zeile zugewiesen wird!

## Variablen speichern Werte, nicht Ausdrücke

Eine Variable hat immer einen *Namen* und einen *Wert*, an den der Name gebunden ist. Der 
Wert kann eine Zahl sein oder ein String oder ein anderer Datentyp:

    seitenlänge = 100

    lustiger_komiker = "Mr Bean"

Variablen können auch Ergebnisse von *Ausdrücken* (Rechnungen) speichern:

    körpergewicht_in_gramm = 62 * 1000

Diese Zuweisung bindet den Namen `körpergewicht_in_gramm` an den Wert 62000. Das wird 
wichtig, wenn du Code wie den folgenden hast:

    körpergewicht = 62

    körpergewicht_in_gramm = körpergewicht * 1000

Was passiert mit dem Wert von `körpergewicht_in_grammn`, wenn du nachträglich den Wert
von `körpergewicht` anpasst? Du kannst es mit folgendem Programm ausprobieren:

```py live_py slim

körpergewicht = 62
körpergewicht_in_gramm = körpergewicht * 1000


körpergewicht = 57

print("Dein Körpergewicht in Gramm:", körpergewicht_in_gramm)

```

Was hast du erwartet? Das Programm könnte zwei Werte ausgeben: 

   1. 57000, wenn `körpergewicht_in_gramm` mit der Änderung des 
   Körpergewichts neu berechnet wird.
   1. 62000, wenn die nachträgliche Änderung von `körpergewicht` keinen 
   Einfluss auf `körpergewicht_in_gramm` hat

Wenn du das Programm ausführst, siehst du, dass Option 2 die Richtige
ist. Das kommt daher, dass eine Zuweisung nicht eine mathenmatische 
Gleichung im mathematischen Sinn ist. Die Zeile

    körpergewicht_in_gramm = körpergewicht * 1000

bedeutet also nicht, dass `körpergewicht_in_gramm` *immer* 1000 mal grösser ist
als `körpergewicht`, sondern dass in dem Moment, in dem die Zuweisung ausgeführt
wird, der Ausdruck auf der rechten Seite der Zuweisung *ausgewertet* wird und der 
Name an das **Ergebnis** gebunden wird, *nicht* an den Ausdruck bzw die Rechnung!

Deshalb kannst du auch mathenmatisch unsinnige Zuweisungen vornehmen wie die folgende:

```py live_py slim
x = 2
x = x + 1
print(x)
```

Die Zeile

    x = x + 1

macht mathenmatisch keinen Sinn und bringt dir im Mathematikunterricht eine ungenügende
Note ein. In der Informnatik ist es aber eine häufig verwendete Zuweisung, die folgendermassen
behandelt wird:

   1. Zuerst schaut Python nach, an welchen Wert `x` gebunden ist (2)
   2. Dann addiert Python 1 zu diesem Wert hinzu (Ergebnis 3)
   3. Zuletzt wird der Name `x` an das Ergebnis des Ausdrucks auf der rechten Seite (also 3)
   gebunden.

Deshalb gibt die `print`-Anweisung den Wert 3 aus.
