# Grafik mit graphics2d

Dieses Kapitel zeigt dir, wie du mit einem kleinen Python-Grafikframework eigene Grafiken
erstellen und auf Tastatur- und Mauseingaben reagieren kannst. 

Eine *Framework* ist ein bereits vorbereitetes Gerüst, in welches du nur noch
deine eigenen fertigen Teile einbauen musst, um ein funktionierendes Ganzes zu 
erhalten.

Moderne Software greift fast immer auf Bibliotheken (Sammlungen von bereits bestehenden
Unterprogrammen) und Frameworks zurück, um nicht jedes Mal das Rad neu erfinden und bei
Null anfangen zu müssen.
